          // Why Helper-Jarvis?
          
The butler your models deserve

          

            Big labs ship chat windows. Helper-Jarvis ships the rest of the assistant:
            the voice, the eyes, the memory and the hands. Plug in the model you like —
            Helper-Jarvis makes it feel like a person who lives in your computer.
          

        

        

          

            

              
            

            
Voice-first interaction

            
Speak naturally, get spoken answers back. Wake-word style activation and live transcription make it feel like the real thing.

          

          

            

              
            

            
Vision & screen awareness

            
Show it an image, a screenshot or your camera feed and ask what's going on. Multimodal models see what you see.

          

          

            

              
            

            
Tools & automation

            
Web search, file operations, app control, scheduled tasks. If your computer can do it, Jarvis should be able to ask it to.

          

          

            

              
            

            
Memory that persists

            
Remembers your preferences, projects and people across sessions — so you stop re-explaining yourself to your own assistant.

          

          

            

              
            

            
API-key private

            
Your keys, your account, your data. Helper-Jarvis talks straight to the provider — no SVTeam middleman server in between.

          

          

            

              
            

            
Open & hackable

            
MIT-licensed and built to be modified. Fork it, theme it, add skills — the whole point is that it's yours.

          

        

      

    


    
    

      

        

          // Under the hood
          
One app, four layers

          

            Helper-Jarvis keeps the interface clean so the layers underneath can evolve.
            Each layer talks through a small, typed surface — swap any part without breaking the rest.
          

        

        

          

            

              Interface
              Voice I/O · chat UI · hotkeys
            

            
Everything you touch: microphone, speakers, the conversation window and the global hotkey that summons your assistant from anywhere.

          

          

            

              Agent core
              Reasoning · tool use · memory
            

            
The brainstem: plans multi-step answers, decides when to call a tool, writes to long-term memory and keeps the conversation coherent.

          

          

            

              Tool belt
              Search · files · system · custom skills
            

            
Typed, permission-gated capabilities the model can call. Add your own with a single function definition.

          

          

            

              Model runtime
              OpenAI-compatible endpoints
            

            
One client for every provider — cloud (OpenAI, Anthropic-compatible gateways, Gemini endpoints) or fully local (Ollama, LM Studio, llama.cpp).

          

        

      

    


    
    

      

        

          // Get started
          
Up and running in minutes

          

            Clone the repo, drop in an API key — any OpenAI-compatible one, including a local
            server — and say hello. No account, no subscription, no telemetry.
          

          
    
            
  • Works with OpenAI, local Ollama, LM Studio & friends
    • 
            
  • Bring your own voice: pick any TTS engine
    • 
            
  • Free forever, MIT licensed
    • 
          

          Full setup guide →
        

        

          

            terminal
            
          

          
git clone https://github.com/SVTeam-Official/Helper-Jarvis.git
cd Helper-Jarvis
pip install -r requirements.txt

# add your key — cloud or local, your call
export OPENAI_API_KEY=sk-...
python main.py
